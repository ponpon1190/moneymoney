# 公司費用報支管理辦法

## 第二章 報支標準 (單筆稽核)

### 2.1 電話費

- **標準**：電話與網路費報支上限為 **NT$ 6000 元**（含稅）。
- **稽核規則**：
  - 單筆餐飲金額 ≤ 6000 元：標示「✅ 符合」
  - 單筆餐飲金額 > 6000 元：標示「❌ 違規超標」

### 2.2 交通費

- **標準**：因公搭乘大眾運輸工具（高鐵、台鐵、捷運、客運）得憑票根或電子發票全額報支。
- **稽核規則**：
  - 高鐵票 / 台鐵票 / 捷運等大眾運輸：標示「✅ 符合」
  - 計程車費：需附事由說明，若無說明標示「待人工確認」

### 2.3 辦公用品與消耗品費

- **標準**：文具、耗材、列印費用等日常辦公用品據實報支。
- **稽核規則**：
  - 一般辦公用品：標示「✅ 符合」
  - 單筆金額超過 NT$ 3,000 元：需先經主管預先核准，否則標示「待人工確認」

### 2.4 租金與維修費

- **標準**：場地/設備租金憑合約或定期收據報支，設備維修憑維修單及發票報支。
- **稽核規則**：
  - 常態性租金、例行設備維修：標示「✅ 符合」

### 2.5 無法辨識或資訊不全

- 發票號碼、日期、商家名稱或金額模糊無法辨識者，合規檢查統一標示為「待人工確認」。

## 第三章 月度營運預算標準與監控 (月度稽核)

### 3.1 常態性預算對照表 (預設上限)

| 報支科目   | 月度預算上限 (NT$) | 說明                       |
| ---------- | ------------------ | -------------------------- |
| 辦公用品費 | $10,000            | 文具、紙張、碳粉等         |
| 消耗品費   | $3,000             | 茶水間消耗品、清潔用品等   |
| 常態性租金 | $15000             | 辦公室租金、影印機租賃費等 |
| 設備維修費 | $15,000            | 辦公設備維修、電腦維護費等 |
| 電話費     | $6000              | 電話費加網路費             |
| 交通費     | $350               | gogoro 月租                |

*備註：若使用者另行指定特定月份或科目的預算上限，請優先以使用者設定之金額為準。*

### 3.2 預算狀態判定規則

- **本月累計金額 ≤ 預算 80%** → 標示「✅ 正常」
- **本月累計金額 80% ~ 100%** → 標示「⚠️ 接近上限」
- **本月累計金額 > 預算 100%** → 標示「❌ 超出預算 (超額 NT$ X,XXX)」
