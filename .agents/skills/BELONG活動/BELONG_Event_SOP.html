📋 Taipei Campus BELONG 活動營運與 CRM 自動化 SOP

活動名稱：Taipei Campus BELONG
參與上限：48 人
主辦團隊：Church Life & Operation
主要系統：Salesforce CRM / SMS / Email

🎯 流程優化四大核心目標

  • 零人工查信：改用 Salesforce 一鍵 RSVP 按鈕，會眾點擊後系統自動寫入出席狀態。
  • 自動化備案：針對未開信者自動觸發 SMS 簡訊提醒，人工電話負擔降低 70%+。
  • 智慧小組媒合：Salesforce Flow 依「可聚會時間」自動比對並指派對應區長與臨時小組。
  • 數據化留存追蹤：區長直接於 CRM 打卡，系統自動生成第 1 週與第 2 週留存率儀表板。

📝 詳細階段作業說明

階段一：活動前預備 (活動當天與結束當天)

步驟 權責單位 作業項目 Salesforce CRM 自動化機制
1.1 Church Life 建立下一次 BELONG 活動 CRM 報名頁面與 QR Code 自動啟用報名表單，確保溝通語言與欄位正確。
1.2 Church Life LINE@ 近期活動設定表 更新專屬 QR Code 選單連結。
1.3 IT / Church Life 設置 Salesforce 自動配對規則 確認區長小組聚會時間與容納人數資料無誤。

階段二：雙階段通知與出席確認 (D-14 ~ D-5)

  • 第一階段通知 (D-14 / 8/30 09:00 AM)：發送帶有 RSVP 按鈕之 Email。一鍵自動更新
  • 自動化簡訊備案 (D-12 / 9/1 10:00 AM)：針對 48 小時內未回覆者自動發送 SMS 提醒簡訊。
  • 電話追蹤與第二階段遞補 (D-11 / 9/2 早上)：下一步團隊於 CRM 界面查看未確認名單進行撥打。下午 2:00 PM 發送第二階段遞補信。
  • 釋出名額通知 (D-5 / 9/8 10:30 AM)：未確認者自動發送名額釋出與預約下期通知。

階段三：小組自動媒合與行前通知 (D-3 ~ D-2)

  • Salesforce 小組自動配對 (D-3 / 9/10)：以「可聚會時間」為第一優先比對，自動分配區長臨時小組並生成區長名單報告。
  • 行前通知 (D-2 / 9/11 10:30 AM)：Email + SMS 發送行前提醒（報到時間 3:45 PM - 4:00 PM，地點 1F 副堂）。

階段四：活動當天與留存追蹤 (D-0 ~ D+14)

  • 現場報到 (D-0 / 9/13)：iPad 掃 Code 快速報到並指派至專屬桌位。
  • 留存追蹤 (D+7 & D+14)：區長於聚會後在 Salesforce 進行點名，即時匯入 Retention Dashboard。

🛠️ 給 IT 團隊的 Salesforce 技術需求規格

  1. RSVP Web Hook / Flow Builder：設定加密動態 URL 帶入 `Registration_ID`，點擊即寫入 `Status` 欄位。
  2. SMS 簡訊 API 串接：整合簡訊平台 API 至 Salesforce Flow 觸發提醒。
  3. Auto-Matching Flow 邏輯：`Available_Time__c == Group.Meeting_Time__c` 自動關聯對應區長與 Campaign。
  4. 儀表板權限設定：開放區長名單視角與 Church Life 專用留存率 Dashboard。
