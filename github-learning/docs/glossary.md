# Git & GitHub 官方權威名詞解釋 (Glossary)

本字典收集 Git 與 GitHub 中最核心的名詞，所有定義均對齊 GitHub Docs 官方詞彙庫與 Pro Git 權威書籍。

---

## A - C

### Branch (分支)
- **官方定義**：A branch is a parallel version of a repository. It is contained within the repository, but does not affect the primary or `main` branch.
- **出處**：*GitHub Docs Glossary / Pro Git 3.1*

### Clone (複製)
- **官方定義**：A clone is a copy of a repository that lives on your computer instead of on a website's server.
- **出處**：*GitHub Docs Glossary*

### Commit (提交)
- **官方定義**：An individual change to a file (or set of files). It's like a snapshot of your repository at a specific point in time.
- **出處**：*Pro Git 1.3 / GitHub Docs*

### Conflict (衝突)
- **官方定義**：The difference between two merged branches that cannot be automatically resolved by Git, requiring manual intervention.
- **出處**：*GitHub Docs - Addressing merge conflicts*

---

## D - F

### Fetch (提取)
- **官方定義**：Fetching gets the latest updates from the remote repository without merging them into your local work.
- **出處**：*Pro Git 2.5*

### Fork (派生 / 複本)
- **官方定義**：A fork is a personal copy of another user's repository that lives on your account. Forks allow you to freely make changes without affecting the original project.
- **出處**：*GitHub Docs - Fork a repo*

---

## G - P

### Git
- **官方定義**：Git is an open source distributed version control system designed to handle everything from small to very large projects with speed and efficiency.
- **出處**：*git-scm.com*

### GitHub
- **官方定義**：GitHub is a code hosting platform for version control and collaboration. It lets you and others work together on projects from anywhere.
- **出處**：*GitHub Docs*

### GitHub Desktop
- **官方定義**：An open-source application that enables you to interact with GitHub using a GUI instead of the command line or a web browser.
- **出處**：*GitHub Desktop Documentation*

### Issue (議題 / 任務)
- **官方定義**：Issues are suggested improvements, tasks, or questions related to the repository.
- **出處**：*GitHub Docs - About issues*

### Merge (合併)
- **官方定義**：Merging takes the changes from one branch and integrates them into another branch.
- **出處**：*Pro Git 3.2*

### Pull Request (PR / 拉取請求)
- **官方定義**：Proposed changes to a repository submitted by a user and accepted or rejected by a repository's collaborators.
- **出處**：*GitHub Docs - About pull requests*

### Push (推送)
- **官方定義**：To send your committed changes to a remote repository on GitHub.
- **出處**：*GitHub Docs Glossary*

---

## R - Z

### Remote (遠端庫)
- **官方定義**：The version of a repository hosted on a server, such as GitHub.com.
- **出處**：*Pro Git 2.5*

### Repository (儲存庫 / 倉庫)
- **官方定義**：The most basic element of GitHub. They're easiest to imagine as a project's folder. A repository contains all of the project files and stores each file's revision history.
- **出處**：*GitHub Docs Glossary*

### Staging Area (暫存區)
- **官方定義**：A file in your Git directory that stores information about what will go into your next commit.
- **出處**：*Pro Git 1.3*

### Working Directory (工作區)
- **官方定義**：The files that you see in your computer's file system when you navigate to a Git repository folder.
- **出處**：*Pro Git 1.3*
